# imagen
Agregamos imagenes enviadas por usuarios de logos de canales, no almacenamos, no trasmitimos ni guardamos contenido de los canales, sólo mantenemos los logos de los canales que estan de forma publica en intenet, ya que es muy dificil encontralos en png este repositorio solo guarda logos en png.

Cualquier reclamo, eliminacion de logo de la base de datos o consulta por favor hacer un "issues" intentaremos responder a la breedad a su requerimiento.
